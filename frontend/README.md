# 🚀 TalentLink – Freelance Collaboration Platform

TalentLink is a modern full-stack freelance marketplace designed to connect skilled professionals with real-world opportunities. It enables seamless collaboration between clients and freelancers through an intuitive and scalable platform.

---

## 🌟 Features

* 🔐 User Authentication (Login/Register with secure validation)
* 👤 User Profiles & Skill Management
* 💼 Project Posting & Management
* 📩 Proposal Submission System
* 💬 Real-time Chat & Messaging
* 🤖 Chatbot Integration for assistance
* ⭐ Reviews & Ratings System
* 📊 Dashboard for users
* 📄 Contract Management

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/leela144/TalentLink.git
cd TalentLink
```

### 2️⃣ Setup Backend

```
cd backend
npm install
npm start
```

### 3️⃣ Setup Frontend

```
cd frontend
npm install
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file in the backend folder and add:

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
